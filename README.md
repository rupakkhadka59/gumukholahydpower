# Gumu Khola Hydropower

A modern, professional website for a hydropower company built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Features

- **Next.js 14+ App Router** for optimal performance and SEO
- **Tailwind CSS (v4)** for responsive, utility-first styling
- **Framer Motion** for subtle, professional animations
- **Lucide React** for crisp, scalable iconography
- **Fully Responsive** design that works flawlessly on mobile, tablet, and desktop
- **Component-based Architecture** for easy maintenance and scaling
- **Mock Data Structure** ready to be connected to a CMS or backend API

## Getting Started

First, ensure you have Node.js installed (v18+ recommended).

1. Clone the repository and navigate into it.
2. Install dependencies:

```bash
npm install
```

3. Run the development server:

```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `app/`: Next.js App Router pages and layouts
- `components/layout/`: Shared layout components (Navbar, Footer)
- `components/ui/`: Reusable UI components (Hero, Cards, Stats)
- `lib/data.ts`: Mock data for projects, stats, team, and news
- `public/`: Static assets

## Customization

You can update the primary colors and typography in `app/globals.css`. 
To modify the mock data, edit `lib/data.ts`.
